Install it

  • Windows: open the file → Install Certificate → Current User → Trusted Root Certification Authorities.
  • macOS: open the file → Keychain Access → double-click "shiftWire CA" → Trust → Always Trust.
  • Linux (Debian/Ubuntu/Kali): sudo cp shiftwire-ca.crt /usr/local/share/ca-certificates/ && sudo update-ca-certificates
  • Firefox: Settings → Privacy & Security → Certificates → View Certificates → Authorities → Import.

Command-line tools and AI agents

  • curl: curl --cacert shiftwire-ca.crt -x http://AGENT:x@127.0.0.1:8080 https://target/ (Windows' built-in curl also needs --ssl-no-revoke: local CAs have no revocation server)
  • Python requests: REQUESTS_CA_BUNDLE=shiftwire-ca.crt   Node: NODE_EXTRA_CA_CERTS=shiftwire-ca.crt
  • Put the agent's name in the proxy username (AGENT above) and shiftWire labels every request it sends.
